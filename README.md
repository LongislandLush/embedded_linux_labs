# Embedded Linux Labs

Hands-on Embedded Linux learning projects and experiments, focusing on cross-compilation, bootloaders, Linux kernel, device drivers, root filesystems, and Buildroot.

## Development Environment

- Host: Ubuntu 24.04 LTS (VirtualBox)
- Target: BeagleBone Black (ARM Cortex-A8)
- Languages: C, Shell
- Tools: GCC, crosstool-NG, QEMU, Git

## Lab Progress

| Lab | Topic | Status |
|---|---|---|
| 01 | ARM Cross-Compilation Toolchain | Completed |

## Learning Objectives

Build practical knowledge of Embedded Linux development, from toolchain setup to board bring-up, kernel configuration, and driver development.
